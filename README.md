# Figly

Make your words ridiculously big. Type text, pick a figlet font, copy the ASCII art.

- Live preview of your text in 41 curated figlet fonts (fonts load on demand)
- Copy ASCII, copy an HTML `<pre>` snippet, or download a `.txt`
- Wrap width, alignment, scale, frames, case, and invert controls
- Share link: text and settings live in the URL
- Runs entirely in the browser, nothing is uploaded

## Stack

Next.js 16 (App Router, Turbopack), TypeScript, Tailwind v4, figlet, lucide-react, Fontsource (Outfit, Plus Jakarta Sans, JetBrains Mono).

## Develop

```bash
npm install
npm run dev
```
